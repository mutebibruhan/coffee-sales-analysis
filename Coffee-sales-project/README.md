# ☕ Coffee Sales Performance Analysis (2019–2022)

An end-to-end sales analytics project analyzing coffee sales performance across the UAE market between 2019 and 2022. This project explores sales trends, customer behavior, product performance, and geographic insights through an interactive dashboard and business-focused analysis.

The objective was to transform transactional sales data into actionable insights that support strategic decision-making.

---

## 📌 Project Overview

A Sales Manager requested an analysis of multi-year coffee sales performance to better understand:

- Revenue trends over time
- Product category performance
- Customer purchasing behavior
- Geographic concentration
- High-value customer patterns
- Growth opportunities across markets

The project combines dashboard design with business intelligence techniques to generate recommendations that can improve sales performance and market strategy.

---

## 🎯 Business Questions

This project answers the following questions:

1. How have sales changed over time?
2. Which coffee products generate the most revenue?
3. Which package sizes drive sales performance?
4. Which regions contribute most to revenue?
5. Who are the highest-value customers?
6. What opportunities exist for future growth?

---

## 📊 Dataset Overview

Analysis Period:

**January 2019 – August 2022**

Dataset Summary:

- **1,000 orders analyzed**
- **AED 45,134 total revenue**
- **AED 45.13 average order value**
- **4 coffee product categories**
- **3 UAE Emirates**
- Multi-year transactional sales data
